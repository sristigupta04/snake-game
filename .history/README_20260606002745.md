# 🐍 Snake Game

A classic Snake Game built with React and JavaScript.

## Features

* Responsive game board
* Keyboard controls (Arrow Keys / WASD)
* Mobile touch controls
* Dynamic game speed
* Score tracking
* Pause and Resume functionality
* Game Over detection
* Win condition when board is full
* Restart game option

## Controls

| Action         | Key       |
| -------------- | --------- |
| Move Up        | ↑ or W    |
| Move Down      | ↓ or S    |
| Move Left      | ← or A    |
| Move Right     | → or D    |
| Pause / Resume | Space Bar |

## How to Play

1. Press **Start** to begin the game.
2. Use Arrow Keys or WASD to move the snake.
3. Eat food to increase your score and grow the snake.
4. Avoid hitting walls or your own tail.
5. Fill the board to win the game.
